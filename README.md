# 📺 Desafio Flexbox - Clone do YouTube
Projeto desenvolvido como desafio prático no Bootcamp da DIO (Digital Innovation One). O objetivo principal foi recriar a interface principal do YouTube para consolidar o aprendizado de estilização e posicionamento web, com foco total em Flexbox.

## 🎯 O Desafio
O maior objetivo deste projeto foi dominar o alinhamento de elementos na tela sem a necessidade de hacks antigos ou floats. O clone foca na estrutura visual da página inicial do YouTube, incluindo:

Header (Cabeçalho): Alinhamento do logo, barra de pesquisa e ícones de usuário.

Sidebar (Menu Lateral): Navegação vertical responsiva e ícones alinhados.

Grid de Vídeos: Organização dos cards de conteúdo de forma fluida utilizando propriedades flexíveis.

## 🛠️ Conceitos Flexbox Praticados
Durante o desenvolvimento, foram aplicadas propriedades essenciais do Flexbox, tais como:

``display: flex;`` para ativar o contexto flex nos containers.

``flex-direction`` para alternar entre layouts em linha (vídeos) e em coluna (sidebar).

``justify-content`` (``space-between``, ``center``) para distribuir o espaço dos elementos do cabeçalho.

``align-items: center;`` para garantir que textos e ícones fiquem perfeitamente alinhados na vertical.

``flex-wrap: wrap;`` para fazer com que a lista de vídeos quebre a linha dinamicamente conforme o tamanho da tela.
